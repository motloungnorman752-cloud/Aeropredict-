# AeroPredict Source Project (Sanitized)

## Quick Start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables:
   ```bash
   cp .env.example .env
   ```
3. Start development server (Express + Vite on port 3000):
   ```bash
   npm run dev
   ```
4. Type-check / build:
   ```bash
   npm run lint
   npm run build
   ```
